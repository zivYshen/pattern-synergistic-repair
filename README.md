- # Pattern-Synergistic Repair

  This repository provides the publicly releasable reproducibility materials for the paper:

  **Pattern Synergistic Repair: Multi-Expert LoRA Fusion for Automated Program Repair**

  Published in *Information and Software Technology*.

  ## Released Materials

  The repository includes:

  - evaluation scripts;
  - training and validation data splits;
  - experimental prompts;
  - diagnostic metric implementations.

  Patent-sensitive materials are excluded from the public release.

  ## Benchmarks

  The evaluation benchmarks used in the paper are publicly available from their original repositories:

  - [Defects4J](https://github.com/rjust/defects4j) — v1.2
  - [HumanEval-Java](https://github.com/ASSERT-KTH/human-eval-java)
  - [Vul4J](https://github.com/aprorg/vul4j)
